# 字体（不随仓库提供，体积太大）

全部是 SIL Open Font License 1.1，可免费商用。下载后把下面这些文件名放进这个文件夹：

| 文件名 | 字体 | 用途 | 下载 |
|---|---|---|---|
| `NotoSansSC.ttf` | Noto Sans SC（可变字重） | 字幕、白纸卡粗黑体 | https://fonts.google.com/noto/specimen/Noto+Sans+SC |
| `Xiaolai-Regular.ttf` | 小赖字体 | 手绘窗口里的手写体 | https://github.com/lxgw/kose-font |
| `fusion-pixel-12px-proportional-zh_hans.ttf` | 缝合像素字体 12px 比例版 | 像素标签 | https://github.com/TakWolf/fusion-pixel-font |
| `fusion-pixel-12px-monospaced-zh_hans.ttf` | 缝合像素字体 12px 等宽版 | 像素屏、计数器 | 同上 |

文件名和上表不一致时，改名或者改 `src/fonts.ts`。代码窗用系统自带的 Cascadia Mono / Consolas。
